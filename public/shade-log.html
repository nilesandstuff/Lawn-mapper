1. The phone

Sensor Logger sends its readings here as it records. Paste this address into it once:

  1. Sensor Logger → Settings → Data Streaming: turn on HTTP Push, paste the address, batch every 10–30 seconds.
  2. Sensors: Light, Location and Orientation on, everything else off. Set Orientation's sample rate to 100 ms (it defaults to 100 a second, which only costs battery and data).
  3. Keep it awake with the screen off. Android → Settings → Apps → Sensor Logger → Battery: Unrestricted. Then Settings → Battery → Background usage limits: make sure Sensor Logger is in none of the sleeping lists (add it to Never sleeping apps). Keep Power saving off while recording. Without this the phone stops the light sensor about a minute after the screen goes off; GPS keeps going, so the track looks fine but has no light.
  4. Phone flat, screen up, on the hopper cover, at the front (the end farthest from you). Record all day: the truck, stops and fills are sorted out here.
  5. No signal? Export the recording (zipped CSV) and upload it below instead.
